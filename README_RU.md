# Инструкция: удалённый SSH-доступ к Raspberry Pi (pi5home)

Эта инструкция для обычного пользователя. Она объясняет, как подключиться к Raspberry Pi из любой точки через интернет, что делать, когда адрес изменился, и как остановить и снова запустить доступ.

Технические подробности (как устроен проект, команды установки, тесты) — в файле `README.md`.

## Что это такое

Raspberry Pi стоит дома и не имеет собственного публичного адреса. Чтобы подключиться к нему извне, используется сервис **ngrok**: он создаёт временный адрес в интернете, который ведёт к SSH на Raspberry Pi.

Важно:
- **Адрес может меняться.** На бесплатном тарифе ngrok адрес выдаётся случайно. Иногда он остаётся прежним, иногда меняется.
- Когда адрес меняется, **Pi записывает готовую команду `ssh` в файл на сервере vdsn2**. Если настроен Telegram, бот присылает то же сообщение.
- Доступ по SSH работает **по ключу**. Для пользователя `bliss` также разрешён вход по паролю.

## Как узнать текущий адрес

**Способ 1. Файл на сервере vdsn2.** С компьютера, у которого есть доступ к vdsn2 от root, выполните:

```bash
ssh root@vdsn2 cat /root/pi5home_ngrok_endpoint.txt
```

В файле одна строка, например `ssh -p 24281 bliss@2.tcp.eu.ngrok.io`. Её можно сразу скопировать и выполнить. Если написано `ngrok tunnel is down`, туннель сейчас не работает.

**Способ 2. Сообщение в Telegram** (если бот настроен). Последнее сообщение от бота содержит адрес и готовую команду для подключения.

**Способ 3. Команда на Raspberry Pi.** Войдите на Pi и выполните:

```bash
cd ~/ngrok_setup
sudo ./setup.sh status
```

В первой строке будет адрес, например:

```text
state=up endpoint=2.tcp.eu.ngrok.io:24281
```

Здесь `2.tcp.eu.ngrok.io` — это **ХОСТ**, а `24281` — это **ПОРТ**.

Если написано `state=down`, туннель сейчас не работает (см. раздел «Если не подключается»).

## Как подключиться

С компьютера, у которого есть ключ для этой Raspberry Pi, выполните:

```bash
ssh -p ПОРТ bliss@ХОСТ
```

Например:

```bash
ssh -p 24281 bliss@2.tcp.eu.ngrok.io
```

Вход происходит по ключу. Если появилось сообщение `Permission denied (publickey)`, значит, на этом компьютере нет нужного ключа. Обратитесь к администратору.

## Если адрес изменился

1. Подождите около минуты после смены адреса. Файл на vdsn2 обновится сам (или придёт сообщение в Telegram).
2. Используйте адрес и порт из **последней** записи (файл содержит только её).
3. Старый адрес больше не работает. Не сохраняйте его в качестве постоянного.

## Если не подключается

1. Подождите 2–3 минуты. Туннель часто восстанавливается сам.
2. Проверьте состояние на Raspberry Pi:
   ```bash
   cd ~/ngrok_setup
   sudo ./setup.sh status
   ```
   - Если `state=up` — туннель работает. Проверьте адрес, порт и ключ на своём компьютере.
   - Если `state=down` — перезапустите туннель:
     ```bash
     sudo systemctl restart ngrok-ssh.service
     ```
     Подождите минуту и снова выполните `status`.
3. Если ничего не помогло, сообщите администратору и приложите вывод команды `status`.

## Как остановить доступ

Чтобы полностью отключить удалённый доступ, выполните на Raspberry Pi:

```bash
sudo systemctl disable --now ngrok-ssh.service
```

Доступ после этого не вернётся сам — ни после перезагрузки, ни через несколько минут.

**Не используйте** `sudo systemctl stop ngrok-ssh.service`. Такая остановка временна: система сама снова включит туннель в течение пары минут.

## Как снова включить доступ

```bash
sudo systemctl enable --now ngrok-ssh.service
```

После этого через минуту файл на vdsn2 обновится с новым адресом (и придёт сообщение в Telegram, если он настроен).

## Что не нужно трогать

- Папку `/usr/local/lib/ngrok-ssh/` — там файлы проекта.
- Файл `.env` и файл `~/.config/ngrok-ssh/telegram.env` — там настройки Telegram (если они есть). Не отправляйте их содержимое в чаты и не публикуйте.
- Файл `/root/pi5home_ngrok_endpoint.txt` на vdsn2 — его пишет Raspberry Pi. Не редактируйте его вручную: при следующей смене адреса он будет перезаписан.
- Файл `~/.config/ngrok/ngrok.yml` — там ключ доступа к ngrok.
- Программы и настройки **Happ (VPN)** и **раздачи интернета через Android**. Проект их не меняет, и менять их ради ngrok не нужно.

## Безопасность

- Не публикуйте адрес и порт там, где их могут увидеть посторонние.
- Не отправляйте токены, ключи и пароли в чаты и письма.
- Для пользователя `bliss` разрешён вход по паролю, поэтому пароль должен быть длинным и надёжным. Ключ остаётся основным способом входа.

## Удаление

Чтобы полностью удалить проект с Raspberry Pi, выполните:

```bash
cd ~/ngrok_setup
sudo ./setup.sh uninstall
```

Будут удалены файлы проекта и службы. Сохранятся настройки Telegram, запомненный последний адрес, программа ngrok и её настройки. Файл на vdsn2 удаляется не автоматически: если он больше не нужен, удалите его вручную.
